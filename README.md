## Установка

1.  Убедитесь, что в вашей системе установлен Python 3.
2.  Клонируйте репозиторий: `git clone https://github.com/KRISTINA-Lap/python-project-49.git`
3.  Перейдите в директорию проекта: `cd python-project-49`
4.  Создайте виртуальное окружение: `python -m venv .venv`
5.  Активируйте виртуальное окружение: `source .venv/bin/activate`
6.  Установите зависимости: `pip install -r requirements.txt`

## Запуск

Запустите игру, выполнив команду `brain-games` в терминале. После запуска вам будет предложено выбрать игру из списка.
